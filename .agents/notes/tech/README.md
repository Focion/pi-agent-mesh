# notes/tech — 技术设计文档

## 收录什么

- 架构设计：模块划分、依赖关系、部署形态
- 实现方案：改动点、关键算法、并发与一致性策略
- 接口与数据模型：API 契约、表结构、消息格式
- 技术决策记录：为什么选 A 不选 B（决策及其约束）

## 不收录什么

- 代码里读得出来的实现细节（避免与代码不同步；写「为什么」而非「是什么」）
- 功能规则与验收标准 → `notes/product/`
- 评审意见 → `notes/review/`

## 命名

`YYYY-MM-DD-<kebab-slug>.md`，如 `2026-09-14-cache-layer-design.md`
