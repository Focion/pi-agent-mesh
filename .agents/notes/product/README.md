# notes/product — 产品设计文档

## 收录什么

- 需求说明 / PRD：要解决谁的什么问题，做成什么样
- 功能规则：状态流转、边界条件、异常提示、权限
- 交互与流程：页面流程、关键交互说明
- 验收标准：怎么算做完

## 不收录什么

- 实现方案、接口设计 → `notes/tech/`
- 排期与任务拆解 → `notes/plan/`
- 选型调研 → `notes/research/`

## 命名

`YYYY-MM-DD-<kebab-slug>.md`，如 `2026-09-14-user-onboarding.md`

## 模板

```markdown
---
title: <功能名>
date: <YYYY-MM-DD>
status: draft
owner: <负责人>
tags: []
related: []
---

## 一句话描述

<这个功能是什么，给谁用。>

## 目标与非目标

- 目标：<要达成的效果，尽量可衡量>
- 非目标：<明确不做的部分，防止范围蔓延>

## 用户与场景

<使用者是谁，在什么场景下用。>

## 功能规则

<逐条列出规则；含边界条件、异常情况、权限限制。>

## 流程 / 交互

<流程描述或图示；截图放 assets/ 并相对引用。>

## 验收标准

- [ ] <可验证的条目>

## 待确认

- <悬而未决的问题及待谁确认>
```
