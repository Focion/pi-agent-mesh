# notes/research — 研究类文档

## 收录什么

- 技术选型对比：候选方案、评估维度、结论与理由
- 可行性分析：能不能做、代价多大、风险在哪
- 竞品 / 现状调研：外部产品或内部系统的做法
- 问题排查中获得的、可复用的原理性结论

## 不收录什么

- 最终采用的实现方案 → `notes/tech/`
- 面向用户的功能定义 → `notes/product/`
- 一次性的搜索记录、没有结论的摘抄

## 命名

`YYYY-MM-DD-<kebab-slug>.md`，如 `2026-09-14-message-queue-options.md`
